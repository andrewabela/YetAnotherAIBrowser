*Yet Another AI Browser* is a web browser that replaces fetching HTML content from websites with AI-generated content. Users will need to provide there own API key. Using local models via Ollama or LmStudio is also supported, making the browser an offline browser.

## Installation
Go to [Releases](https://github.com/andrewabela/YetAnotherAIBrowser/releases) and download the version for your platform.

## Configuration
When running for the first time, go the setting and configure your preferred generative AI provider, model, and API key. Then you can go right ahead entering websites URLs in the address bar.
